## 1. はじめに

本アプリは、訪問系サービスで働く特定技能外国人の **研修記録** と **OJT（同行訪問）記録** を管理するためのWebアプリです。

**このアプリでできること：**
- 研修5大項目の実施記録・進捗管理
- OJT（同行訪問）のステップ管理（ステップ②〜⑦）
- 到達目標8項目のチェックシート管理
- 巡回訪問時に提出する帳票のPDF出力
- 指導者・管理者ごとの進捗ダッシュボード

**対応デバイス：** スマートフォン・タブレット・PC（スマホでの利用を想定して設計しています）

**アプリのURL：** デプロイ後に発行されるVercelのURLにアクセスしてください。

## 3. 画面の見方

### スマートフォンの場合

画面の下に **5つのタブ** が常に表示されます：

```
┌──────────────────────────────────────────┐
│                                          │
│          （メイン画面の内容）               │
│                                          │
├──────┬──────┬──────┬──────┬──────────────┤
│ 🏠   │ 👥   │ 📖   │ 📋   │ ⚙️           │
│ダッシュ│外国人 │研修   │ OJT  │ 管理         │
│ボード │一覧  │記録   │ 記録  │（管理者のみ）  │
└──────┴──────┴──────┴──────┴──────────────┘
```

| タブ | 説明 |
|------|------|
| **ダッシュボード** | ホーム画面。全体の進捗が一目で分かります |

| **研修記録** | 研修セッションの記録・進捗確認 |

### パソコンの場合

画面の左側にサイドバーとして同じメニューが表示されます。

## 4. 管理者アカウントの初期設定

> この手順は **初回セットアップ時のみ** 必要です。通常はシステム担当者が行います。

### 4-1. Supabaseにアクセス

1. ブラウザで [https://supabase.com/dashboard](https://supabase.com/dashboard) を開きます
2. ログインします（Googleアカウントまたはメールで登録）

### 4-2. プロジェクトを選択

1. ダッシュボードから **「ojt-training-app」** プロジェクトをクリックします

### 4-3. 管理者ユーザーを作成

1. 左メニューから **「Authentication」** をクリック
2. **「Users」** タブを開きます
3. 右上の **「Add user」** → **「Create new user」** をクリック
4. 以下を入力します：

| 項目 | 入力内容 |
|------|---------|
| Email | 管理者のメールアドレス（例：yamashita@aco-care.jp） |
| Password | パスワード（8文字以上、英数字混合を推奨） |
| Auto Confirm User | **ON** にする |

5. **「Create user」** をクリック
6. 作成されたユーザーの **User UID** をメモします（長い英数字の文字列）

### 4-4. 管理者プロフィールを登録

1. 左メニューから **「Table Editor」** をクリック
2. テーブル一覧から **「profiles」** をクリック
3. **「Insert row」** をクリック
4. 以下を入力します：

| カラム | 入力内容 |
|--------|---------|
| id | 先ほどメモした **User UID** を貼り付け |
| email | 管理者のメールアドレス |
| name | 名前（例：山下） |
| role | **admin** を選択 |
| facility_id | 所属事業所のID（事業所を先に登録してください） |

5. **「Save」** をクリック

> これで管理者アカウントの作成は完了です。アプリにログインできるようになります。

## 5. スタッフ・指導者アカウントの追加

### 方法A：Supabaseから追加（推奨）

[4-3](#4-3-管理者ユーザーを作成) と同じ手順でSupabaseからユーザーを作成し、profilesテーブルに追加します。**role** には以下を設定してください：

| ロール | 設定値 | 対象者 |
|--------|--------|--------|
| 管理者 | `admin` | 事業所の管理者（山下さんなど） |
| 指導者 | `trainer` | 研修を実施する現場スタッフ |
| 指導責任者 | `supervisor` | 研修計画の承認を行う責任者 |
| 経営側 | `executive` | 進捗を閲覧するのみ（あーちゃんなど） |

### 方法B：アプリの管理画面から役割を変更

すでにアカウントが作成されているスタッフの **役割（ロール）** を変更する場合：

1. 画面下の **「管理」** タブをタップ
2. **「スタッフ管理」** を開きます
3. 変更したいスタッフの行にある **ロール選択** ドロップダウンを変更します

```
┌─────────────────────────────────────┐
│ スタッフ管理                          │
├─────────────────────────────────────┤
│                                     │
│  山下  admin@aco-care.jp            │
│  ロール: [管理者     ▼]              │
│  施設:  ACOケア訪問介護事業所         │
│                                     │
│  田中  trainer@aco-care.jp          │
│  ロール: [指導者     ▼]              │
│  施設:  ACOケア訪問介護事業所         │
│                                     │

```

## 6. 事業所の登録・管理

### 事業所を新規登録する

1. 画面下の **「管理」** タブをタップ
2. **「事業所管理」** を開きます
3. **「新規追加」** ボタンをタップ
4. 以下を入力します：

| 項目 | 入力内容 |
|------|---------|
| 事業所名 | 例：ACOケア訪問介護事業所 |
| 住所 | 例：東京都○○区△△ 1-2-3 |
| 種別 | 訪問介護 / 居宅介護 などを選択 |

5. **「保存」** をタップ

### 事業所を編集・削除する

- 一覧で事業所名の横にある **「編集」** ボタンで情報を変更できます
- **「削除」** ボタンで削除できます（確認ダイアログが表示されます）

> **注意：** 事業所を削除すると、その事業所に紐づくデータに影響が出る場合があります。

3. 登録フォームに以下を入力します：

| 項目 | 入力内容 | 必須 |

4. **「登録」** ボタンをタップ

1. **「外国人一覧」** → 対象者をタップ → **「研修記録」** ボタンをタップ
   または **「研修記録」** タブから直接アクセス

2. 研修5大項目が一覧表示されます：

```

│ 研修進捗                             │
│ ラジュ・タパ / ACOケア訪問介護事業所   │

├─────────────────────────────────────┤
│                                     │
│ ① 訪問系サービスの基本事項  [未着手]  │
│   0回実施 / 目標 1回                 │
│   0.0h / 1h             0%          │
│   ████░░░░░░░░░░░░░░░░░░░░░         │
│   サブトピック: 0 / 8 完了     ＞     │
│                                     │
│ ② 生活支援技術            [未着手]   │
│   0回実施 / 目標 6回                 │

│ ④ 日本の生活様式          [未着手]   │
│ ⑤ 緊急時の対応            [未着手]   │
│                                 [+] │
└─────────────────────────────────────┘
```

### 8-2. 研修セッションを記録する

1. 記録したい研修項目（例：①訪問系サービスの基本事項）をタップ
2. 研修項目の詳細画面が開きます
3. **「セッション追加」** ボタンをタップ（または右下の **＋** ボタン）
4. 以下を入力します：

| 項目 | 入力内容 | 説明 |
|------|---------|------|
| 実施日 | 日付を選択 | デフォルトは今日の日付 |
| 開始時間 | 例：09:00 | 研修の開始時刻 |
| 終了時間 | 例：10:00 | 研修の終了時刻 |
| 指導者 | ドロップダウンから選択 | 実際に研修を行ったスタッフ |
| 実施形式 | 対面/OJT/ロールプレイ/シミュレーション | 研修の方法 |
| 実施した細目 | チェックボックスで選択 | この回で教えた内容にチェック |
| 備考 | 自由記入 | 特記事項があれば |

5. **「保存」** をタップ

> **ポイント：** 1回の研修で全ての細目を教える必要はありません。複数回に分けて少しずつチェックを入れていきます。

### 8-3. 進捗の確認ポイント

- **プログレスバー**: 累計時間が目標時間に対して何%かを表示
- **サブトピック**: 全細目にチェックが入ると緑色の完了マークがつきます
- **ステータス**: 未着手 → 進行中 → 完了 と自動で変わります

### 8-4. 研修項目の承認（指導責任者・管理者）

全ての細目にチェックが入り、目標時間に到達すると、**「承認」** ボタンが表示されます：

1. 研修項目の詳細画面を開く
2. 画面下部に表示される **「この研修項目を承認する」** ボタンをタップ
3. 確認ダイアログで **「承認する」** をタップ

## 9. OJT記録の入力

### 9-1. OJT対象利用者を登録する

OJTは **利用者ごと** に記録します。まず対象利用者を登録します。

1. **「OJT記録」** タブをタップ
2. 対象の外国人を選択
3. **「利用者追加」** ボタンをタップ
4. 以下を入力：

| 項目 | 入力内容 | 説明 |
|------|---------|------|
| 利用者イニシャル | 例：A.T. | 個人情報保護のためイニシャルで |
| 訪問頻度 | 週1回 / 週2回 / 週3回以上 | 必要な同行期間が自動計算されます |
| OJT開始日 | 日付を選択 | OJTを開始する日 |

5. **「追加」** をタップ

### 9-2. OJTステップの流れ

OJTは以下の **6ステップ** で進みます（報告書に完全準拠）：

```
② 利用者・家族への説明
    ↓ pass
③ 事前研修
    ↓ pass
④ OJT 1回目（見学）  ←─┐
    ↓ pass              │ 問題があれば
⑤ OJT 2回目（メイン） ──┘ 差し戻し
    ↓ pass              │
⑥ OJT 3回目（独立）  ──┘
    ↓ pass
⑦ OJT完了判定
```

### 9-3. OJT記録を入力する

1. OJT対象の利用者をタップ
2. ステップのタイムライン画面が表示されます

```
┌─────────────────────────────────┐
│ OJTステップ                      │
│                                 │
│  ✅ ② 利用者・家族への説明       │
│  │     2026/3/10 完了            │
│  │                              │
│  🔵 ③ 事前研修          ← 現在   │
│  │     進行中                    │
│  │                              │
│  ○ ④ OJT 1回目（見学）          │
│  │                              │
│  ○ ⑤ OJT 2回目（メイン）        │
│  │                              │
│  ○ ⑥ OJT 3回目（独立）          │
│  │                              │
│  ○ ⑦ OJT完了判定               │
│                                 │
│            [記録追加]             │
└─────────────────────────────────┘
```

3. **「記録追加」** ボタンをタップ
4. 以下を入力します：

| 項目 | 入力内容 |
|------|---------|
| ステップ | 現在のステップが自動選択されています |
| 実施日 | 日付を選択 |
| 同行者 | 同行した職員をドロップダウンから選択 |
| 実施内容 | 実施した内容を記入 |

5. **到達目標チェックシート**（8項目）を入力します：

各項目について **本人評価** と **指導者評価** をそれぞれ選択します：

| 記号 | 意味 |
|------|------|
| ○ | 良好（できている） |
| △ | おおむね良好（もう少し） |
| × | 不十分（できていない） |

**8つの評価項目：**
1. サービス内容の手順を理解しているか
2. サービス内容を実施できているか
3. 緊急体制・連携を理解しているか
4. 記録・報告ができているか
5. 他職種と連携できているか
6. 利用者とコミュニケーションが取れているか
7. アセスメント記録により利用者の状態像を理解しているか
8. 個別援助計画に沿った支援を提供できているか

6. **判定** を選択します：

| 判定 | 意味 |
|------|------|
| 次へ進む | 問題なし。次のステップへ進みます |
| 再実施 | もう一度同じステップを実施します |
| 差し戻し | 前のステップからやり直します |

7. **「保存」** をタップ

> **注意：** ステップの繰り返しや差し戻しの履歴は全て保存されます。何回目の実施かも自動で記録されます。

## 10. 最終到達目標評価

全てのOJTが完了したら、**最終到達目標評価** を行います。

### 10-1. 評価画面を開く

1. **「外国人一覧」** → 対象者をタップ → **「最終評価」** ボタンをタップ

### 10-2. 評価を入力する

1. 8項目それぞれについて **本人評価** と **指導者評価** を ○/△/× で選択
2. **「総合コメント」** 欄に指導責任者のコメントを記入
3. **「保存」** をタップ

### 10-3. 管理者が承認する

1. 評価が保存されると、管理者・指導責任者に **「承認」** ボタンが表示されます
2. 内容を確認のうえ **「承認する」** をタップ
3. 承認日と承認者名が記録されます

### 10-4. キャリアアップ計画の更新期限

承認から **12ヶ月** が経過する前に、画面上部に以下のアラートが表示されます：

```
┌─────────────────────────────────────┐
│ ⚠️ キャリアアップ計画の更新期限が     │
│   近づいています                      │
│   期限: 2027年3月10日                │
└─────────────────────────────────────┘
```

3. PDFファイルが自動的にダウンロードされます
4. ダウンロードしたPDFを印刷してご使用ください

### 11-4. 各帳票の内容

| 帳票名 | 内容 | 用途 |
|--------|------|------|
| **研修記録票** | 研修項目ごとの細目チェックリスト、セッション履歴、累計時間、署名欄 | 巡回訪問時提出 |
| **OJT記録票** | ステップ②〜⑦の全履歴、到達目標チェックシート、署名欄 | 巡回訪問時提出 |
| **最終評価票** | 8項目の到達目標評価（本人・指導者）、総合コメント、4者署名欄 | 巡回訪問時提出 |

> **署名欄について：** PDFを印刷後、指導者・指導責任者・本人が手書きで署名してください。

## 12. ダッシュボードの使い方

ログイン後の最初の画面が **ダッシュボード** です。役割によって表示内容が異なります。

### 管理者ビュー

| セクション | 内容 |
|------------|------|
| **サマリーカード** | 外国人総数、研修完了率、OJT進行中/完了数 |
| **研修進捗一覧** | 全外国人の研修5項目の状態を色付きドットで表示 |
| **OJT進捗一覧** | 進行中のOJTの利用者・現在のステップ |
| **未実施アラート** | まだ研修が完了していない外国人と未実施項目 |

**ドットの色の意味：**
- 🟢 緑 = 完了
- 🔵 青 = 進行中
- ⚪ グレー = 未着手

### 指導者ビュー

| セクション | 内容 |
|------------|------|
| **担当外国人** | 自分が研修を担当している外国人の進捗 |
| **未指導の細目** | まだ教えていない研修細目の一覧 |
| **次回OJT予定** | 同行者として担当しているOJTの次のステップ |

### 経営側ビュー

全事業所を横断した進捗サマリーが表示されます（読み取り専用）：
- 全体の研修完了率・OJT完了率
- 事業所ごとの進捗比較
- 外国人ごとの進捗一覧

## 13. よくあるご質問

### Q: 研修を複数回に分けて記録できますか？

**A:** はい。1つの研修項目に対して複数の「セッション」を追加できます。例えば「②生活支援技術」を3/10、3/14、3/17と3回に分けて記録し、それぞれの回で教えた細目にチェックを入れることができます。累計時間は自動で計算されます。

### Q: OJTのステップを差し戻した場合、履歴は消えますか？

**A:** 消えません。全ての実施履歴（何回目の実施か含む）が保存されます。差し戻しの判定も記録として残ります。

### Q: 指導者と指導責任者は同じ人でもよいですか？

**A:** はい。管理者が指導責任者を兼ねる場合は、同じアカウントで操作できます。ただし、セッションごとの「指導者」（実際に教えた人）と「指導責任者」（承認する人）は明確に分離されています。

### Q: スマートフォンで写真を撮って記録に添付できますか？

**A:** 現在のバージョンでは写真の添付機能はありません。将来のアップデートで対応予定です。備考欄にテキストで記録してください。

### Q: PDFが文字化けします

**A:** PDFには日本語フォント（Noto Sans JP）が組み込まれています。通常は文字化けしません。問題が発生する場合は、別のPDFビューアで開いてみてください。

### Q: パスワードを忘れました

**A:** 管理者に連絡してください。Supabaseの管理画面からパスワードをリセットできます。

### Q: 巡回訪問の提出書類は何を印刷すればよいですか？

**A:** 以下の3種類を印刷してください：
1. **研修記録票**（研修項目ごと、最大5枚）
2. **OJT記録票**（利用者ごと）
3. **最終評価票**（1枚）

いずれも厚労省「訪問系サービスの要件に係る報告書」に準拠した体裁です。
