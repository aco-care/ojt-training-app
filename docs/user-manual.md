## 1. はじめに

本アプリは、訪問系サービスで働く特定技能外国人の **研修記録** と **OJT（同行訪問）記録** を管理するためのWebアプリです。

**このアプリでできること：**
- 研修5大項目の実施記録・進捗管理
- OJT（同行訪問）のステップ管理（ステップ①〜⑦）
- 到達目標8項目のチェックシート管理
- 研修・OJTの予定をカレンダーで管理
- 巡回訪問時に提出する帳票のPDF出力
- 指導者・管理者ごとの進捗ダッシュボード
- スタッフの追加・パスワード管理
- フィードバック（要望・不具合報告）の送信

**対応デバイス：** スマートフォン・タブレット・PC（スマホでの利用を想定して設計しています）

**アプリのURL：** https://ojt-training-app.vercel.app

---

## 2. ログイン方法

### 手順

1. アプリのURLにアクセスします
2. **ログイン画面** が表示されます
3. 登録済みの **メールアドレス** と **パスワード** を入力します
4. 「**ログイン**」ボタンをタップします

> **ログインできない場合：** メールアドレスまたはパスワードが間違っています。管理者に確認してください。

> **パスワードを忘れた場合：** ログイン画面の「パスワードを忘れた方」をタップするか、管理者にパスワードリセットを依頼してください。

## 3. 画面の見方

### スマートフォンの場合

画面の下に **7つのタブ** が常に表示されます：

| タブ | 説明 |
|------|------|
| **ダッシュボード** | ホーム画面。全体の進捗が一目で分かります |
| **外国人一覧** | 登録されている特定技能外国人の一覧 |
| **予定管理** | 研修・OJTの予定をカレンダーで管理 |
| **研修記録** | 研修セッションの記録・進捗確認 |
| **OJT記録** | OJT（同行訪問）の記録・進捗確認 |
| **ヘルプ** | よくある質問と使い方ガイド |
| **管理** | 事業所・スタッフの管理（管理者のみ表示） |

### パソコンの場合

画面の左側にサイドバーとして同じメニューが表示されます。

### 画面右上のアイコン

- **通知ベル**: 新しい通知がある場合、赤いバッジで件数が表示されます
- **ログアウト**: アプリからログアウトします

## 4. スタッフの追加・管理

> **この機能は管理者のみ使用できます。**

### 4-1. 新しいスタッフを追加する

1. 画面下の **「管理」** タブをタップ
2. **「スタッフ管理」** 画面が表示されます
3. **「新しいスタッフを追加」** ボタンをタップ
4. 以下を入力します：

| 項目 | 入力内容 | 必須 |
|------|---------|------|
| 氏名 | スタッフの名前 | ○ |
| メールアドレス | ログインに使用するメールアドレス | ○ |
| 初期パスワード | 6文字以上（初回ログイン後に変更を推奨） | ○ |
| 役割 | 下記の5つから選択 | ○ |
| 資格 | 未取得 / 初任者研修取得済 / 介護福祉士取得済 | - |
| 所属施設 | 複数選択可能。主な施設を1つ選択 | - |

5. **「登録」** をタップ

### 役割（ロール）の種類

| 役割 | できること |
|------|----------|
| **管理者** | 全データの閲覧・編集、スタッフ管理、PDF出力 |
| **指導者** | 担当外国人の研修・OJT記録の入力 |
| **指導責任者** | 研修・OJTの承認、最終評価の承認 |
| **特定技能外国人** | 自分の記録の閲覧、自己評価の入力 |
| **経営側** | 全事業所の進捗ダッシュボードの閲覧（読み取り専用） |

### 4-2. スタッフ情報を編集する

1. スタッフ一覧で **「編集」** ボタンをタップ
2. 役割・資格・所属施設を変更できます
3. **「保存」** をタップ

### 4-3. パスワードをリセットする

1. スタッフ一覧で **「PW変更」** ボタンをタップ
2. 新しいパスワード（6文字以上）を入力
3. **「変更する」** をタップ

> スタッフ本人がパスワードを忘れた場合、管理者がこの機能でリセットしてください。

### 4-4. 退職・異動処理

- **退職処理**: スタッフが退職した場合にアーカイブします。研修記録やOJT記録は保持されます。
- **異動処理**: スタッフが他の事業所に異動した場合に使用します。
- **復元**: アーカイブしたスタッフを「退職・異動済み」タブから復元できます。

## 5. 事業所の登録・管理

> **この機能は管理者のみ使用できます。**

### 事業所を新規登録する

1. 画面下の **「管理」** タブをタップ
2. **「施設管理」** を開きます
3. **「施設を追加」** ボタンをタップ
4. 以下を入力します：

| 項目 | 入力内容 |
|------|---------|
| 事業所名 | 例：ACOケア訪問介護事業所 |
| 住所 | 例：東京都○○区△△ 1-2-3 |
| 種別 | 訪問介護 / 居宅介護 などを選択 |

5. **「保存」** をタップ

### 事業所を編集・削除する

- 一覧で **「編集」** ボタンで情報を変更できます
- **「削除」** ボタンで削除できます（確認ダイアログが表示されます）

> **注意：** 事業所を削除すると、その事業所に紐づくデータに影響が出る場合があります。

## 6. 特定技能外国人の登録

### 新規登録する

1. 画面下の **「外国人一覧」** タブをタップ
2. 右上の **「新規登録」** ボタンをタップ
3. 登録フォームに以下を入力します：

| 項目 | 入力内容 | 必須 |
|------|---------|------|
| 氏名 | フルネーム（例：ラジュ・タパ） | ○ |
| 国籍 | ドロップダウンから選択（ネパール、ベトナムなど） | - |
| 生年月日 | カレンダーから選択 | - |
| 所属事業所 | ドロップダウンから選択 | ○ |
| 経験年数 | 数字で入力（例：1） | - |
| 備考 | 自由記入 | - |

4. **「登録」** ボタンをタップ

### 詳細を確認する

一覧で名前をタップすると **詳細画面** が開きます。ここから以下にアクセスできます：

- **研修記録** → 研修の進捗確認・セッション追加
- **OJT記録** → OJT同行訪問の記録
- **最終評価** → 到達目標のチェックシート
- **PDF出力** → 帳票の印刷

## 7. 予定管理（カレンダー）

研修やOJTの予定をカレンダー形式で管理できます。

### 7-1. カレンダーの見方

- **月表示・週表示・日表示** を切り替えられます
- **「前」「次」** ボタンまたはスワイプで前後の月/週/日に移動
- **「今日」** ボタンで今日に戻ります
- 予定はカレンダー上に色付きで表示されます：
  - 青 = 予定（未実施）
  - 黄 = 入力中
  - 緑 = 完了
  - グレー = キャンセル

### 7-2. 予定を追加する

1. **「予定管理」** タブをタップ
2. **「＋ 予定追加」** ボタンをタップ
3. 予定の種類を選択します：

**研修予定の場合：**

| 項目 | 入力内容 |
|------|---------|
| 対象外国人 | ドロップダウンから選択 |
| 研修項目 | 5大項目から選択 |
| 実施日 | カレンダーから選択 |
| 開始時間・終了時間 | 時間を選択 |
| 指導者 | 担当する指導者を選択 |

**OJT予定の場合：**

| 項目 | 入力内容 |
|------|---------|
| 対象外国人 | ドロップダウンから選択 |
| OJT利用者 | 登録済みの利用者から選択 |
| OJTステップ | ①〜⑦から選択 |
| 実施日 | カレンダーから選択 |
| 開始時間・終了時間 | 時間を選択 |
| 同行者 | 同行する職員を選択 |

4. **「保存」** をタップ

> **時間の重複チェック：** 同じ外国人に同じ日時で予定が入っている場合、警告が表示されます。

### 7-3. 予定の編集・複製・削除

カレンダー上の予定カードに表示されるボタンから操作できます：
- **詳細**: 予定の詳細画面を開きます
- **編集**: 予定の内容を変更します
- **複製**: 同じ内容で新しい予定を作成します
- **削除**: 予定を削除します（確認ダイアログが表示されます）

### 7-4. 予定の取り消し・延期

予定の詳細画面から、指導責任者・管理者が予定を取り消し・延期できます。

## 8. 研修記録の入力

### 8-1. 研修進捗画面を開く

1. **「外国人一覧」** → 対象者をタップ → **「研修記録」** ボタンをタップ
   または **「研修記録」** タブから直接アクセス

2. 研修5大項目が一覧表示されます：
   - ① 訪問系サービスの基本事項
   - ② 生活支援技術
   - ③ コミュニケーション
   - ④ 日本の生活様式
   - ⑤ 緊急時の対応

### 8-2. 研修セッションを記録する

1. 記録したい研修項目をタップ
2. 研修項目の詳細画面が開きます
3. **「セッション追加」** ボタンをタップ（または右下の **＋** ボタン）
4. 以下を入力します：

| 項目 | 入力内容 | 説明 |
|------|---------|------|
| 実施日 | 日付を選択 | デフォルトは今日の日付 |
| 開始時間 | 例：09:00 | 研修の開始時刻 |
| 終了時間 | 例：10:00 | 研修の終了時刻 |
| 指導者 | ドロップダウンから選択 | 実際に研修を行ったスタッフ |
| 実施形式 | 対面/OJT/ロールプレイ/シミュレーション | 研修の方法 |
| 実施した細目 | チェックボックスで選択 | この回で教えた内容にチェック |
| 備考 | 自由記入 | 特記事項があれば |

5. **「保存」** をタップ

> **ポイント：** 1回の研修で全ての細目を教える必要はありません。複数回に分けて少しずつチェックを入れていきます。

### 8-3. 進捗の確認ポイント

- **プログレスバー**: 累計時間が目標時間に対して何%かを表示
- **サブトピック**: 全細目にチェックが入ると緑色の完了マークがつきます
- **ステータス**: 未着手 → 進行中 → 完了 と自動で変わります

### 8-4. 研修項目の承認（指導責任者・管理者）

全ての細目にチェックが入り、目標時間に到達すると、**「承認」** ボタンが表示されます：

1. 研修項目の詳細画面を開く
2. 画面下部に表示される **「この研修項目を承認する」** ボタンをタップ
3. 確認ダイアログで **「承認する」** をタップ

## 9. OJT記録の入力

### 9-1. OJT対象利用者を登録する

OJTは **利用者ごと** に記録します。まず対象利用者を登録します。

1. **「OJT記録」** タブをタップ
2. 対象の外国人を選択
3. **「利用者追加」** ボタンをタップ
4. 以下を入力：

| 項目 | 入力内容 | 説明 |
|------|---------|------|
| 利用者イニシャル | 例：A.T. | 個人情報保護のためイニシャルで |
| 訪問頻度 | 週1回 / 週2回 / 週3回以上 | 必要な同行期間が自動計算されます |
| OJT開始日 | 日付を選択 | OJTを開始する日 |

5. **「追加」** をタップ

### 9-2. OJTステップの流れ

OJTは以下のステップで進みます（報告書に完全準拠）：

```
① 利用者の選定・マッチング
    ↓
② 利用者・家族への説明
    ↓
③ 事前研修
    ↓
④ OJT（見学）      ←─┐
    ↓                  │ 問題があれば
⑤ OJT（メイン）    ──┘ 差し戻し
    ↓                  │
⑥ OJT（独立）      ──┘
    ↓
⑦ OJT完了判定
```

### 9-3. OJT記録を入力する

1. OJT対象の利用者をタップ
2. ステップのタイムライン画面が表示されます
3. **「記録追加」** ボタンをタップ
4. 以下を入力します：

| 項目 | 入力内容 |
|------|---------|
| ステップ | 現在のステップが自動選択されています |
| 実施日 | 日付を選択 |
| 同行者 | 同行した職員をドロップダウンから選択 |
| 実施内容 | 実施した内容を記入 |

5. **到達目標チェックシート**（8項目）を入力します：

各項目について **本人評価** と **指導者評価** をそれぞれ選択します：

| 記号 | 意味 |
|------|------|
| ○ | 良好（できている） |
| △ | おおむね良好（もう少し） |
| × | 不十分（できていない） |

**8つの評価項目：**
1. サービス内容の手順を理解しているか
2. サービス内容を実施できているか
3. 緊急体制・連携を理解しているか
4. 記録・報告ができているか
5. 他職種と連携できているか
6. 利用者とコミュニケーションが取れているか
7. アセスメント記録により利用者の状態像を理解しているか
8. 個別援助計画に沿った支援を提供できているか

6. **判定** を選択します：

| 判定 | 意味 |
|------|------|
| 次へ進む | 問題なし。次のステップへ進みます |
| 再実施 | もう一度同じステップを実施します |
| 差し戻し | 前のステップからやり直します |

7. **「保存」** をタップ

> **注意：** ステップの繰り返しや差し戻しの履歴は全て保存されます。何回目の実施かも自動で記録されます。

## 10. 最終到達目標評価

全てのOJTが完了したら、**最終到達目標評価** を行います。

### 10-1. 評価画面を開く

1. **「外国人一覧」** → 対象者をタップ → **「最終評価」** ボタンをタップ

### 10-2. 評価を入力する

1. 8項目それぞれについて **本人評価** と **指導者評価** を ○/△/× で選択
2. **「総合コメント」** 欄に指導責任者のコメントを記入
3. **「保存」** をタップ

### 10-3. 管理者が承認する

1. 評価が保存されると、管理者・指導責任者に **「承認」** ボタンが表示されます
2. 内容を確認のうえ **「承認する」** をタップ
3. 承認日と承認者名が記録されます

### 10-4. キャリアアップ計画の更新期限

承認から **12ヶ月** が経過する前に、画面上部にアラートが表示されます。

## 11. PDF出力（帳票印刷）

巡回訪問時に提出する帳票をPDFで出力できます。

### 11-1. PDF出力画面を開く

1. **「外国人一覧」** → 対象者をタップ → **「PDF出力」** ボタンをタップ

### 11-2. 出力できる帳票

| 帳票名 | 内容 | 用途 |
|--------|------|------|
| **研修記録票** | 研修項目ごとの細目チェックリスト、セッション履歴、累計時間、署名欄 | 巡回訪問時提出 |
| **OJT記録票** | ステップ①〜⑦の全履歴、到達目標チェックシート、署名欄 | 巡回訪問時提出 |
| **最終評価票** | 8項目の到達目標評価（本人・指導者）、総合コメント、4者署名欄 | 巡回訪問時提出 |

### 11-3. PDFをダウンロードする

1. 出力したい帳票の **「PDF出力」** ボタンをタップ
2. ボタンが「生成中...」に変わります（数秒お待ちください）
3. PDFファイルが自動的にダウンロードされます
4. ダウンロードしたPDFを印刷してご使用ください

> **署名欄について：** PDFを印刷後、指導者・指導責任者・本人が手書きで署名してください。

## 12. ダッシュボードの使い方

ログイン後の最初の画面が **ダッシュボード** です。役割によって表示内容が異なります。

### 管理者ビュー

| セクション | 内容 |
|------------|------|
| **サマリーカード** | 外国人総数、研修完了率、OJT進行中/完了数 |
| **研修進捗一覧** | 全外国人の研修5項目の状態を色付きドットで表示 |
| **OJT進捗一覧** | 進行中のOJTの利用者・現在のステップ |
| **未実施アラート** | まだ研修が完了していない外国人と未実施項目 |

**ドットの色の意味：**
- 緑 = 完了
- 青 = 進行中
- グレー = 未着手

### 指導者ビュー

| セクション | 内容 |
|------------|------|
| **担当外国人** | 自分が研修を担当している外国人の進捗 |
| **未指導の細目** | まだ教えていない研修細目の一覧 |
| **次回OJT予定** | 同行者として担当しているOJTの次のステップ |

### 経営側ビュー

全事業所を横断した進捗サマリーが表示されます（読み取り専用）：
- 全体の研修完了率・OJT完了率
- 事業所ごとの進捗比較
- 外国人ごとの進捗一覧

## 13. 通知機能

画面右上の **通知ベル** アイコンで、新しい通知を確認できます。

### 通知が届くタイミング

- フィードバックの対応状況が更新されたとき（送信者に通知）
- 新しいフィードバックが送信されたとき（管理者に通知）

### 通知の確認方法

1. 画面右上の **ベルアイコン** をタップ
2. 通知一覧が表示されます
3. 未読の通知は青色の背景で表示されます
4. **「既読にする」** をタップすると既読になります

> 通知は自動的に30秒ごとに更新されます。

## 14. フィードバック（要望・不具合報告）

アプリの改善要望や不具合の報告ができます。

### 14-1. フィードバックを送る

1. 画面右下の **青い丸ボタン** をタップ
2. フィードバックフォームが表示されます
3. **カテゴリ** を選択します：
   - **UI改善**: 画面の見た目や使いやすさの改善
   - **機能追加**: 新しい機能の要望
   - **バグ報告**: 動作の不具合
   - **その他**: 上記以外
4. **内容** に詳細を記入します
5. **「送信」** をタップ

> 送信すると管理者に通知が届きます。

### 14-2. フィードバックの管理（管理者のみ）

1. **「管理」** タブから **フィードバック管理** を開きます
2. タブで表示を切り替えられます：すべて / 未対応 / 対応中 / 対応済み
3. **「対応する」** ボタンで対応状況の変更・返信ができます
4. ステータスを変更すると、送信者に通知が届きます

## 16. よくあるご質問

### Q: 研修を複数回に分けて記録できますか？

**A:** はい。1つの研修項目に対して複数の「セッション」を追加できます。例えば「②生活支援技術」を3/10、3/14、3/17と3回に分けて記録し、それぞれの回で教えた細目にチェックを入れることができます。累計時間は自動で計算されます。

### Q: OJTのステップを差し戻した場合、履歴は消えますか？

**A:** 消えません。全ての実施履歴（何回目の実施か含む）が保存されます。差し戻しの判定も記録として残ります。

### Q: 指導者と指導責任者は同じ人でもよいですか？

**A:** はい。管理者が指導責任者を兼ねる場合は、同じアカウントで操作できます。ただし、セッションごとの「指導者」（実際に教えた人）と「指導責任者」（承認する人）は明確に分離されています。

### Q: カレンダーで予定の時間が重複したらどうなりますか？

**A:** 同じ外国人に同じ日時で予定を入れようとすると、時間の重複が検出され警告が表示されます。次の空き時間が自動で提案されます。

### Q: スマートフォンで写真を撮って記録に添付できますか？

**A:** 現在のバージョンでは写真の添付機能はありません。備考欄にテキストで記録してください。

### Q: PDFが文字化けします

**A:** PDFには日本語フォント（Noto Sans JP）が組み込まれています。通常は文字化けしません。問題が発生する場合は、別のPDFビューアで開いてみてください。

### Q: パスワードを忘れました

**A:** 管理者に連絡してください。管理画面の「PW変更」ボタンからパスワードをリセットできます。

### Q: 巡回訪問の提出書類は何を印刷すればよいですか？

**A:** 以下の3種類を印刷してください：
1. **研修記録票**（研修項目ごと、最大5枚）
2. **OJT記録票**（利用者ごと）
3. **最終評価票**（1枚）

いずれも厚労省「訪問系サービスの要件に係る報告書」に準拠した体裁です。
