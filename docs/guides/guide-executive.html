吉兆 研修・OJT管理システム
経営側ガイド

このアプリは、特定技能外国人の研修・OJTの進捗を一覧で把握するためのシステムです。

あなたの役割：経営側（executive）
全事業所を横断した進捗ダッシュボードの閲覧と、帳票のPDF出力ができます（読み取り専用）。
アプリのURL（ブラウザでアクセス / QRコードをスキャン）
https://ojt-training-app.vercel.app
初回ログイン：管理者からの招待メールに記載されたリンクからパスワードを設定してください。設定後、上記URLからメールアドレスとパスワードでログインできます。

1できること

全体の進捗を確認する

ダッシュボードに全事業所の研修完了率・OJT完了率がサマリーカードで表示されます。

ダッシュボード（ログイン後の最初の画面）

事業所別の進捗を比較する

各事業所の研修・OJT進捗率が一覧で比較できます。

ダッシュボード → 事業所別セクション

PDFを出力する

巡回訪問用の研修記録票・OJT記録票・最終評価票をPDF出力できます。

外国人一覧 → 対象者 → PDF出力

2困ったとき

アプリ内の「ヘルプ」タブで操作方法を確認できます。解決しない場合は画面右下の青いボタンからフィードバックを送信してください。
