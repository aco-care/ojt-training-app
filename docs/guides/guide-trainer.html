吉兆 研修・OJT管理システム
指導者ガイド

このアプリは、特定技能外国人の研修・OJTを記録するためのシステムです。

あなたの役割：指導者（trainer）
担当する外国人の研修記録・OJT記録の入力と、予定の確認・作成ができます。
アプリのURL（ブラウザでアクセス） https://ojt-training-app.vercel.app
初回ログイン：管理者からの招待メールに記載されたリンクからパスワードを設定してください。設定後、上記URLからメールアドレスとパスワードでログインできます。

1やってほしいこと

ダッシュボードで担当外国人を確認する

ログインするとダッシュボードに、自分が担当している外国人の進捗が表示されます。

ダッシュボード（ログイン後の最初の画面）

研修記録を入力する

研修を実施したら、日付・時間・実施した細目を選択して記録します。

研修記録 → 外国人選択 → 研修項目選択 → セッション追加

OJT記録を入力する

OJT（同行訪問）を実施したら、実施日・到達目標チェックシートを入力します。

OJT記録 → 外国人選択 → 利用者選択 → 記録追加

予定を確認する

カレンダーで自分に割り当てられた研修・OJTの予定を確認します。新しい予定の作成もできます。

予定管理

2ポイント

  • 研修は1回で全てを教える必要はありません。複数回に分けて細目にチェックを入れていきます
  • 研修時間は自動で計算されます（休憩時間は差し引かれます）
  • OJTは7ステップで進みます。各ステップで到達目標をチェックしてください

3困ったとき

アプリ内の「ヘルプ」タブで操作方法を確認できます。解決しない場合は画面右下の青いボタンからフィードバックを送信してください。
