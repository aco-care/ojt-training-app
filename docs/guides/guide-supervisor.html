吉兆 研修・OJT管理システム
指導責任者ガイド

このアプリは、特定技能外国人の研修・OJTを記録・管理するためのシステムです。

あなたの役割：指導責任者（supervisor）
研修・OJTの予定作成と承認、最終評価の入力・承認、スタッフ管理、PDF出力ができます。
アプリのURL（ブラウザでアクセス / QRコードをスキャン）
https://ojt-training-app.vercel.app
初回ログイン：管理者からの招待メールに記載されたリンクからパスワードを設定してください。設定後、上記URLからメールアドレスとパスワードでログインできます。

1やってほしいこと

研修・OJTの予定を作成する

カレンダーから研修予定やOJT予定を作成します。指導者と外国人を割り当てます。

予定管理 → ＋ 予定追加

研修記録を確認・承認する

指導者が入力した研修記録を確認し、全細目完了後に承認します。

研修記録 → 外国人選択 → 項目選択 → 承認

OJT記録を確認する

OJTのステップ①〜⑦の進捗を確認します。

OJT記録 → 外国人選択 → 利用者選択

最終評価を入力・承認する

8項目の到達目標評価を入力し、承認します。

外国人一覧 → 対象者 → 最終評価

PDFを出力する

巡回訪問用の研修記録票・OJT記録票・最終評価票をPDF出力します。

外国人一覧 → 対象者 → PDF出力

2指導者への展開

指導者（trainer）には別途「指導者向けガイド」をお渡しください。指導者は研修記録・OJT記録の入力が主な役割です。

3困ったとき

アプリ内の「ヘルプ」タブで操作方法を確認できます。解決しない場合は画面右下の青いボタンからフィードバックを送信してください。
