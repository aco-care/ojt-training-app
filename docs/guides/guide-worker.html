あなたのガイド

このアプリは、あなたの けんしゅう（研修）と OJT（しごとのれんしゅう）の きろく を かんり するものです。

あなたができること
じぶんの けんしゅう と OJT の しんちょく を かくにん できます。
じこひょうか（自己評価）を にゅうりょく できます。
アプリのURL（ブラウザでアクセス / QRコードをスキャン）
https://ojt-training-app.vercel.app
はじめてのログイン：メールにとどいたリンクから パスワードを せっていしてください。そのあと、上の URL から メールアドレスとパスワードで ログインできます。

1ダッシュボードを みる

ログインすると、さいしょの がめん（ダッシュボード）に あなたの けんしゅう の しんちょく が ひょうじされます。

ダッシュボード（ログインご の がめん）

2じこひょうか を にゅうりょく する

OJT の じこひょうか
OJT の きろく で、じぶんの ひょうか（○ △ ×）と コメント を いれます。

ダッシュボード → OJT りようしゃ名 を タップ

さいしゅう ひょうか の ほんにん ひょうか
8こ の もくひょう について、じぶんの ひょうか（○ △ ×）を いれます。

ダッシュボード → さいしゅうひょうか
